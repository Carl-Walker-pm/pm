## Zenzap

This environment is connected to Zenzap as the **Cursor Agent** bot.

1. Accept the workspace invite emailed to your account (or open the join link from the agent chat).
2. After joining, manage API keys at [app.zenzap.co/console](https://app.zenzap.co/console).
3. Local credentials (gitignored): `.env.zenzap`
4. Connectivity check: `python3 scripts/zenzap_ping.py`
